情景和种子是什么意思？

平稳海湾：默认规则，居民可以制造和使用渔网。
没有渔网：禁止制造和使用渔网，用于比较工具的影响。
捕鱼冲击：第 15—17 天捕鱼产量减半，用于观察冲击后的变化。

种子：影响同价订单的撮合顺序。相同种子、规则和居民计划可以复现同一撮合结果；不同种子不保证结果一定不同。
