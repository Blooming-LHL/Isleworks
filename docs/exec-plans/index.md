# 执行计划与实施记录

| 位置 | 用途 | 当前内容 |
| --- | --- | --- |
| `active/` | 正在执行的计划：目标、进度、阻碍与验收条件 | 当前没有独立在执行的计划文档；启动下一项工作时创建 |
| `completed/` | 已结束批次的执行记录：结果、验证证据与遗留事项 | [历史实施记录](completed/IMPLEMENTATION.md) |
| [tech-debt-tracker.md](tech-debt-tracker.md) | 跨批次持续跟进的技术债、限制与待验收事项 | 当前待办及证据入口 |

执行计划结束后移入 `completed/`，保留结果与验证证据，并将尚未解决的事项转入技术债清单或明确的后续计划。归档表示该实施批次结束，不表示全部产品目标已经完成。

产品规格与设计决策分别保留在 [产品规格](../product-specs/index.md) 和 [设计文档](../design-docs/index.md)，不会因为实现完成而移入 `completed/`。
