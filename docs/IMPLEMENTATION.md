# Isleworks 实施记录

更新日期：2026-11-08。项目根目录：`/Users/lhl/Projects/Isleworks`。

## 已实现

- 标准库 Python 3.11 模块化核心，6 居民、30 日、每日四劳动块。
- 捕鱼、纤维、渔网制造和损耗、饥饿退出、库存约束、确定性市场撮合与结算。
- 无渔网和捕鱼冲击对照场景。
- 先生成每日草案再提交；SQLite 日终快照、配置哈希、决策和模型调用记录；离线精确重放。
- 独立规则基线；精简 ResidentDecision v1、私有上下文、持久计划与事件触发重规划；程序确定性绑定身份、日期与 ID。
- 模型失败追踪：结构化阶段/代码/字段路径/规则说明、居民与日期关联、降级原因落库、限长脱敏失败输出，以及离线 `diagnose` 命令；解析与计划校验失败时将具体原因反馈给有限重试。
- DeepSeek 显式调用入口、次数预算、超时与有限重试；新居民决策默认 Strict submit_decision，复盘保持 JSON。鉴权或不确定请求关闭运行内调用通道，居民降级休息，世界继续。
- 项目根目录 `.env` 配置入口与 `.env.example` 模板；支持密钥、Base URL 和模型名，程序自动追加 `/chat/completions`，系统环境变量及 CLI 参数可覆盖；兼容原 `DEEPSEEK_ENDPOINT` 配置。
- 本地网页观察器：实验创建、运行状态、暂停、单步、历史日期、库存与计划、事件与曲线。
- 确定性指标和事实报告；结束后自动 LLM 复盘接口；有证据引用和单参数边界的资源提案；五组种子的规则基线配对筛选。

## v0.3 实现

- 精简模型输出为 goal、rationale、days，订单不再由模型填写身份与 ID；限定包装规范化留痕，歧义拒绝。
- DeepSeek 适配器使用正确 Beta 路由、function.strict、强制 submit_decision 与非思考模式；明确验证工具类型、真实调用 ID 和唯一工具，禁止静默换模式。
- 当天只读预检覆盖连续制造、顺序采集、合并预留、工具所有权与市场依赖；未来计划每天复用前重新检查。配方常量与执行引擎共享，经济数值未变。
- 结构、动作与传输共用两次请求额度，纠错保留完整失败候选和多项错误；放不下完整上下文时停止额外请求。未知完成状态不自动补发。
- 个体失败始终使用四块休息与空订单；预算耗尽不暂停世界，合法旧计划可复用，其余居民休息，照常消费与承担饥饿后果。
- 区分 model、reused_plan、fallback_rest、rule_baseline；指标区分主动/模型休息与失败休息，观察器显示降级标识，未提交草案不混入经济统计。
- 持久化协议、提示词、编译器、预检、适配与有效路由身份；中断恢复可复用已准备决策或已审计成功响应。旧协议可读可重放，新实验使用新协议。
- 传输注入的离线实验与真实 HTTP 实验在元数据中明确区分。模型输出若回显密钥，在编译及归档前拒绝。
- 观察器关闭时会结束本地后台规则运行，避免关闭后继续写归档。
